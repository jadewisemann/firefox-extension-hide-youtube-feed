# firefox-extension-hide-youtube-feed

this repository if fork of [chrome-extension-hide-youtube-feed](https://github.com/JoSangHyeon1234/chrome-extension-hide-youtube-feed) by [JoSangHyeon1234](https://github.com/JoSangHyeon1234), for firefox.

## how to use

1. clone this repository. `git clone https://github.com/jadewisemann/firefox-extension-hide-youtube-feed`
2. open `about:debugging` at firefox
3. at "temporary extension", click "Load Temporary Add-on..."
4. select `manifest.json` inside of this clone repository.
